# Romantic frustration and attitudes toward female promiscuity — reproducibility materials

**Companion reproducibility files for the methodological review** “Does Romantic Frustration Make Men Want to Restrict Women's Sexual Freedom?” (Revisiting Date Psychology).

This repository contains transcribed published summary statistics, runnable Python code, computed results, and four figures accompanying a critique of Alexander's November 30, 2024 [Date Psychology survey post](https://datepsychology.com/frustrated-mating-fear-of-extrapair-defection-and-low-sexual-risk-taking-predict-negative-attitudes-toward-female-promiscuity/).

> **Scope.** This is a reconstruction from *published rounded correlations and reported effect sizes*, **not** a replication using the original survey microdata. The survey's original respondent-level data, individual pairwise sample sizes, and analysis scripts were not supplied. The code does **not** generate or impute participant records. All adjusted correlations, regressions, and sample-size checks have corresponding limitations.

## Reproduce the results and figures

Python **3.10+** is recommended. At the repository root, run:

```bash
python -m pip install -r requirements.txt
python reproduce_frustrated_mating_figures.py
```

The script checks that the correlation matrix is internally valid, verifies the two correlations involved in the source article's text-versus-table error, and prints its numerical results. It overwrites the two generated CSVs, results text file, and four PNG figures **in the same directory**. No internet connection is required at runtime.

## Methods and interpretation

**Figure 1 — reported correlations.** The three correlations between frustrated mating (FM) and personal restrictions (AP1), social restrictions (AP2), and scenario approval (PS) are transcribed directly from Table 1. The displayed intervals are the author's own published intervals, not calculated from an assumed sample size.

**Figure 2 — reconstructed regression.** The original six-variable correlation matrix supplies the three-predictor block `RXX` for FM, sexual risk-taking (RT), and perceived threat (PT). For each outcome, the program calculates standardized coefficients by solving `RXX × beta = rXY` and model `R² = beta' × rXY`. The *incremental R²* from adding FM is the difference between the full model and a two-predictor RT/PT model. This is **unique conditional linear predictive information**, not a direct causal effect or the total effect of frustration. Conditioning on potential mediators could remove a real indirect effect; common causes or reverse causation also fit the data. The algebraic decomposition of `r(FM,Y)` in the generated output is **not a mediation analysis**.

**Sample-size check.** The code inverts published Fisher-*z* CI widths to derive approximate effective sample sizes for FM's three outcome correlations and computes illustrative Fisher CIs at `n=213` and `n=284`. The source supplies only rounded estimates and confidence bounds. The numerical proximity to the expected male subsample (about 213 men out of 284 participants) **does not establish that Table 1 is male-only**. Missing-data treatment and CI estimator are unknown; exact *p*-values, multiplicity corrections, or a confirmed analytic *n* cannot be established.

**Figure 3 — causal illustrations.** Competing possible explanations are conceptual, not estimated structural models. The diagram is deliberately not a causal discovery claim.

**Figure 4 — separate experiments.** Inputs were taken from Gul et al. (2026): Study 1 male *d*=.08 (*p*=.452), Study 2 overall *d*=.27 (*p*=.002), with male *d*=.34 (*p*=.003) and female *d*=.18 (*p*=.146) subgroup comparisons. The Study 2 condition-by-sex interaction was not significant (*p*=.349). Effects measured **support for feminine honor**, not romantic frustration and not Alexander's exact survey measures. Study 1 was nonsignificant. The bars depict **reported estimates without invented confidence intervals**.

The code's *r*=.14 power values are approximations based on Fisher's transformation with a two-sided α=.05 test. They are sensitivity illustrations, not power calculations reported by Alexander. All inferential results are subject to rounding and unknown exact sample sizes.
